# Sensitivity Analysis with SpeedyWeather.jl 

Note: The code is currently already part of a [PR in the main repository](https://github.com/SpeedyWeather/SpeedyWeather.jl/pull/876) of SpeedyWeather.jl. Once some remaining issue for longer rollouts are figured out a continously updated version will become part of the reposiotry and documentation. The code in this repository will not be updated and is just used as an archive for the paper. 

We demonstrate the differentiability of SpeedyWeather by conducting a sensitivity analysis of the temperature ${\mathcal J} = T_f$ of the lowest atmospheric layer at a grid point in Denmark ($55^\circ$ N, $11^\circ$ E) over a short integration of the model. We compute derivatives $\frac{\partial T_f}{\partial \mathbf{P}_0}$ of the final temperature $T_f$ after 6 hours and 2 days of integration with respect to the initial conditions of the prognostic variables $\mathbf{P}_0 = \{ \zeta_0, \ln {p_s}_0, T_0\}$. This sensitivty analysis is performed in the script `checkpointed_sensitivity.jl`, the script `sensitivity-plots.jl` plots the results using GeoMakie. The exact results we computed for the paper are archived in the `data` folder.
